Phase 10.5 را اجرا می‌کنم. ابتدا Mini-Player، audio manager و تمام ScrollView/FlatListهای اصلی را پیدا می‌کنم تا padding فقط وقتی Mini-Player فعال است اعمال شود و هیچ صفحه‌ای از قلم نیفتد؛ سپس دکمهٔ توقف کامل صدا را به manager سراسری وصل می‌کنم.

Mini-Player را به‌عنوان یک overlay واقعی نگه می‌دارم اما فضای انتهای همهٔ اسکرول‌های اصلی را از همان state سراسری audio manager می‌گیرم. برای دکمهٔ بستن هم layout داخلی را از Pressable تو‌در‌تو جدا می‌کنم تا با زدن X ناخواسته Player باز نشود و stop/unload به‌طور کامل اجرا شود.

برای padding سراسری، یک hook کوچک بر پایهٔ subscription فعلی audio manager اضافه می‌کنم و آن را به wrapper اسکرول‌های کیبوردی + FlatList/ScrollViewهای اصلی وصل می‌کنم. در نتیجه با فعال شدن Mini-Player، حدود ۹۶ پیکسل فضای امن انتهای محتوا اضافه می‌شود و با بستن آن خودکار حذف می‌گردد.

padding سراسری اکنون برای Home، Archive، Search، Graph و Recommendation فعال است و wrapper مشترک هم Track Detail، فرم‌های افزودن و Settings را پوشش می‌دهد. حالا typecheck و bundle را اجرا می‌کنم تا هم stop/unload جدید و هم استایل‌های responsive بررسی شوند.

Bundle اندروید و typecheck هر دو موفق‌اند. یک بررسی نهایی بصری و کدی انجام می‌دهم تا مطمئن شوم دکمهٔ X روی خود Mini-Player قرار گرفته، مسیرهای بدون داده هم سالم‌اند، و padding پویا به همهٔ اسکرول‌های اصلی رسیده است.

در preview یک warning واقعی پیدا شد: direction استایل معتبر React Native نیست و باید حذف شود. برای حفظ جای دقیق دکمهٔ X، آن را به‌صورت absolute در سمت راست Mini-Player می‌گذارم؛ ردیف کنترل‌های Player هم بدون این property و با ترتیب صریح rewind، play، repeat می‌ماند.

Preview نهایی بدون خطای direction بالا آمد و workflow هم سالم است؛ فقط warningهای شناخته‌شدهٔ expo-av و shadow باقی مانده‌اند. برای پایان، artifact به‌روزشده را دوباره ثبت می‌کنم و سپس خلاصهٔ تغییرات و مسیر تست Expo Go را می‌دهم.

Phase 10.5 تکمیل شد.
